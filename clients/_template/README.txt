Template for a new client. Do not copy by hand: run
  node scripts/new-client.mjs <id> "Academy Name" --owner "Full Name"
then edit clients/<id>/client.json and replace clients/<id>/logo.svg (single-colour mark, square viewBox).
Optional: put icon-192.png, icon-512.png and icon-apple.png in clients/<id>/icons/ to use your own app icons,
and a logo.svg in clients/<id>/icons/ to use a full-colour logo tile (only fill="#rrggbb" colours are kept).
